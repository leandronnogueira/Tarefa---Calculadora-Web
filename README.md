## Por que JavaScript

Fiz em JavaScript puro porque a calculadora é um projeto pequeno uma tela só, poucos botões e pouca coisa pra controlar. Pra isso o Vue não ia ajudar muito e ia acrescentar coisa que não precisava, como importar a biblioteca e aprender a estrutura dele. fica mais simples de entregar, porque são só três arquivos e abre direto no navegador.
